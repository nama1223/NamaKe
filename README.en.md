## Overview

A collection of calculation tools for those everyday "quick calculations."
The reason it's labeled "for private use" is because many of the tools are designed for personal use and not intended for generalization. However, if you find them useful, please feel free to use them as well.

### 11 Tools in Total
Simple Calculator / Number Counter
Day Calculator / Time Difference Calculator / "Year" Calculator
Budget Calculator / Split Bill / External Browser URL for LINE
NamaStopwatch (Namasu) / Reverse Calculation To-Do List / Assigning To-Do List
You can also sort the list. Descriptions of each tool are as follows:

### Simple Calculator
A simple calculator that can perform basic arithmetic operations. Input is done using large keys, and the calculation formula and result are displayed. There are three memo fields at the bottom.

I added this because it's called a calculator; even the creator hardly uses it.

### Number Counter
I modeled it after the traffic volume survey tool.

There are 10 save slots, which you can switch between to count.

Because of its simplicity, the buttons are large to reduce the stress of operation.

It seems like it could be useful in many situations, such as counting people or tallying numbers.

The bigger hurdle may be thinking of using it in the first place.

### Day Calculator
Calculates how many days before or after a given date and displays it on a calendar.
The author created this to maintain a secondary line for Povo.

### Time Difference Calculator
Setting the start and end times calculates the elapsed time.
The result is displayed as "hours:minutes" as well as the sum of minutes.
The author sometimes has to write down the start and end times of use at public facilities, and also needs to calculate and write down the usage time, so created this thinking, "This seems inconvenient in situations like this."
But I tend to do the calculations mentally.

### "Year" Calculator
・Conversion between Western and Japanese calendars
Implemented this because remembering how to calculate it is troublesome.
Supports conversion between all eras from Meiji to Reiwa.

* Birthday ⇔ Age
It can easily convert between the two, but with a little twist.
(1) You can specify a birthday and then specify a reference date other than "today" for calculations. For example, you can see your age as of 3 months ago.
(2) When converting age to birthday, you can calculate things like, "If you were 45 years old 3 days ago, between what year, month, and day you were born?"

### Budget and Expenditure Calculator
For frugality.
Set your budget first, and then add expenses one by one; the income and expenses will be calculated automatically.
Suitable for lighter uses than a household ledger, or rather, completely for personal use.

### Splitting the Bill
I made this because I thought it would be nice to have something like this in a calculator.
I widened the adjustment range, but it became a little difficult to read.

* Allows for price adjustments by dividing participants into multiple groups (e.g., men, women, non-drinkers).
* Allows for rounding prices to avoid small change.
* Allows for choosing whether to leave a surplus or deficit, and settings to allow the organizer to cover or receive the difference.

Note: The word "group" was chosen to reduce the number of characters displayed on the screen.

### External Browser URL for LINE
When you paste a URL into a LINE chat, it opens in LINE's internal browser. However, adding `?openExternalBrowser=1` to the end of the URL will redirect to an external browser.

Since it's long and cumbersome to memorize and input, I incorporated it into my custom app.

It can be attached to URLs in the clipboard or added to manually entered URLs.

### NamaStopwatch (Namasu)

The development purpose is "measuring song durations for concerts."

Since manually noting song titles and durations after measuring would stop the ensemble performance, I made it possible to set these beforehand and record them all together.

First, you create a "song list," and then add song titles to it to create a stopwatch for each song.

The start screen for timing has a large tap area, making it easy to press even while holding an instrument.

There's also a simple lock to prevent accidentally resuming a song that's already been timed.

There's also a tallying function, allowing you to display the total time for all songs and add estimated break times for the actual performance.

The screen layout is designed for screenshots for distribution to members, and there's also a button to copy the text.

──However, I haven't actually used it yet, so there are many rough details.

### Reverse Calculation To-Do
A very personal feature. APK version recommended.

This is a To-Do list that works backward from the time you need to leave, outlining preparations and travel arrangements.

You set the "Action" and "Estimated Completion Time."

For example, if you set an action to be completed by 12:00, and include 20 minutes for eating, 30 minutes for bathing, and 10 minutes for packing, the start and end times for each will be displayed from 11:00.

It has many features to simplify input.

* Actions can be combined and saved as "Action Sets."

* Completion Times can be saved with a name.
(For example, saving the time to take the train to arrive at Tokyo Station at a certain time.)

* Saving a "Full Set" combining the above two allows for one-touch setup.

To accommodate people who set multiple alarms, you can set up to three completion times simultaneously.

[APK Version (Android App Version) Only]
You can set sounds or vibrations to indicate when an action should start.

Different sounds play for completion times 1-3.

Do↑Do↓Do/DoSo/Do♭MiSo

### Assigning To-Do
PC or APK version recommended. It is primarily intended for PC use.

A To-Do list for people who procrastinate and can't get started.

[Basic Functions]
- If you only set a "to-do" name and leave it alone, it will periodically remind you.
- If you also set a "start time," it will remind you if you don't press the start button at that time.

[Survival Check] Function (Can be turned off)
After starting, it will periodically check "Are you really doing it?".
You can complete the survival check by holding your hand over the camera.
If left unattended, it will make a loud noise.

[Digression] Function
A button to press when you need to go to the restroom or just want to look something up online.
Survival checks will stop, and the time will not be calculated.
If you return before the time runs out, it will greet you with a "Welcome back!" animation.
If left unattended after the time runs out, it will make a loud noise.

[Praise] Function
When you start and finish an action, it will praise you with something like "Well done."
The praise is not fixed but AI-generated, and you can also choose the character setting. (Up to 6 fixed types, up to 3 custom types)

### Common Functions
Setting notification sounds (select sound type from alarm sound/notification sound, and also select tone), loading and exporting settings (export data to a .nmk file for backup or device migration; when loading, you can select items and overwrite them), resetting menu order to default, checking for updates, installing as an app, etc. Date and time input supports both direct input by tapping and dial adjustment by dragging up and down.
