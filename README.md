## 概要

日々の「ちょっと計算したい」を集めた計算ツール集。
「プライベート用途」と銘打っているのは、汎用化する気のない自分向け仕様が多めだからで、便利そうなら他の方にもどんどん使って欲しい次第です。

### ツール全11種
単なる電卓／数をかぞえるやつ
日数計算機／時間差計算／「年」計算機
予算収支計算機／ワリカン／LINE用外部ブラウザURL
NamaStopwatch（なます）／逆算ToDo／やらせるToDo
一覧の並べ替えもできます。各ツールの説明は以下の通りです。

### 単なる電卓
四則演算ができる、シンプルな電卓です。大きめのキーで入力し、計算式と結果が表示されます。下部にメモ欄が3つあります。
計算機と名乗るので付けてみただけで、作者自身もほぼ未使用。

### 数をかぞえるやつ
交通量調査のあれをマネしました。
保存枠が10枠あり、切り替えて数えられます。
シンプルゆえにボタンを大きくして操作のストレスを減らしました。
人数確認とか集計とか、地味に使える場面も多そうな。
使うことを「思いつく」ハードルの方が高そうですが。

### 日数計算機
基準日から見て何日前、または何日後の日付を計算し、カレンダーにも表示します。
作者の場合、Povoのサブ回線を維持するために作りました。

### 時間差計算
開始時間と終了時間を設定すると、経過時間が計算されます。
結果は「時：分」の他に分数の合計でも表示されます。
作者の場合、公共施設で利用開始時間と終了時間を書くことがあり、利用時間も計算して書かないといけないので「こういう時不便なことありそうだな」と作ってみました。
でも暗算しがちです。

### 「年」計算機
・西暦⇔和暦の変換
計算の仕方を覚えるのが面倒なので実装しました。
令和から明治までの相互変換に対応。

・誕生日⇔年齢
普通に相互変換できる上、ひとひねり加えてあります。
(1)誕生日を指定した上で、基準日を「今日」以外に指定して計算できる。3ヶ月前現在での年齢を見たい、とか
(2)年齢→誕生日の場合、「3日前の時点で45歳なら、何年の何月何日～何月何日までに産まれたか」のような計算が可能

### 予算収支計算機
倹約向け。
予算を先に設定し、出費を一件ずつ追加していくと収支が自動計算されます。
家計簿より軽い用途向きというか、完全に自分用。

### ワリカン
計算機だからこういうのあってもいいかな、と作ってみたもの。
調整範囲を広くしてみたら、少し見づらくなってしまいました。

・複数にグループ(班)分けして価格調整できる(男性・女性・飲まない人、みたいな)
・小銭が出ないようにキリを良くできる
・端数を余らせるか不足させるか選べ、幹事が一人で負担したりもらっちゃう設定もできる

なお、「班」という単語を選んだのは画面内の字数を減らすためです。

### LINE用外部ブラウザURL
LINEのトークにURLを貼るとLINEの内部ブラウザで開かれてしまいますが、URLの終わりに ?openExternalBrowser=1 をつけると外部ブラウザへ誘導できます。
長くて暗記も入力も面倒なので、自作アプリに盛り込みました。
クリップボード内のURLにくっつけたり、手動で入れたURLに付与したりできます。

### NamaStopwatch（なます）
開発用途は「演奏会へ向けた、曲の時間計測」。
測った後に手書きで曲名やら時間をメモしていると合奏が止まるので、それらを先に設定できるように、そしてまとめて記録できるようにしました。

まず「曲リスト」を最初に作成し、その中に曲のタイトルを追加していくと曲ごとのストップウォッチが作成できます。
計測開始画面はタップエリアを巨大にしてあります。楽器を構えてても押しやすいように。
また、誤タップで計測済みの曲を再開してしまわないように簡易ロックもついています。

集計機能もあり、全曲の時間を合計して表示できたり、本番の休憩想定時間を追加したりできます。
メンバー配布ようにスクリーンショットを想定した画面構成にしつつ、テキストでコピーするボタンもあります。

──ただし、まだ実際に使ってないので細部が色々と雑

### 逆算ToDo
すごく自分用の機能。APK版が推奨。

出かける時刻から逆算して、支度や移動の段取りを並べるToDoです。
設定するのは「行動」と「完了予定時刻」。
たとえば12:00完了予定で、「行動」に食事20分・入浴30分・荷造り10分をセットすると、11:00からそれぞれの開始・終了時間が表示されます。

入力を省略するための機能が豊富。
・「行動」は組み合わせて「行動セット」を保存できる
・「完了予定時刻」は名前をつけて保存できる
(東京駅に何時に着くための電車に乗る時間、のような保存の仕方)
・上記２つを組み合わせた「フルセット」を保存しておけば一発でセット出来る

目覚ましを複数セットするタイプの人でも使えるように、完了予定時刻は同時に３つまでセットできます。

【APK版（Android用アプリ版）限定】
行動を開始すべき時刻に音やバイブを鳴らせます。
完了予定時刻１～３でそれぞれ違う音が鳴ります。
ド↑ド↓ド／ドソー／ド ♭ミ ソー

### やらせるToDo
PC、もしくはAPK版推奨。どちらかといえばPCでの利用を想定。
うだうだしていて行動を開始できない、という人のためのToDo。

【基本機能】
・「やること」の名前だけ設定して放置すると定期的に催促する
・「開始時間」も設定した場合、その時間に開始ボタンを押さないと催促する

【生存確認】機能 (オフも可)
開始してから定期的に「ほんとにやってる？」と確認して来ます。
カメラに手をかざすことで生存確認完了します。
放置するとやかましく鳴ります。

【脱線】機能
ちょっとお手洗い！とか、今だけネットで調べ物したい！とかいう時に押すボタン。
生存確認が停止し、活動時間からも計算外になります。
時間切れになる前に戻ると「おかえり！」って演出つきで迎えてくれます。
時間切れで放置するとやかましく鳴ります。

【褒める】機能
行動を開始して、終わらせた時に「よくやったね」的な感じで褒めてくれます。
褒め言葉は固定ではなくＡＩ生成で、キャラクター設定も選べます。（固定６種・カスタム３種まで）

### 共通機能
通知音の設定（音の種別はアラーム音／通知音から選択、音色も選べます）、設定の読み込み・出力（データを.nmkファイルに書き出してバックアップや端末の引っ越しができ、読み込み時は項目を選んで上書きできます）、メニューの並び順を初期配置に戻す、更新チェック、アプリとしてインストールなどがあります。日付や時刻の入力は、タップで直接入力と上下ドラッグのダイヤル調整の両方に対応しています。
